## Diagnostic refusals and unknowns

Treat a topographic `skip`, `refuse`, or `inconclusive` as meaningful evidence. Read complete diagnostics, including per-band coefficient validity. If the user specifically requests an experimental forced branch, retain the normal branch, label forced use and assumptions, and evaluate separately. Do not force a gate merely to get files written.

A zero cloud bit with no cloud source means unknown cloud status. Missing DEM/sibling geometry is not repaired by zeros unless the algorithm explicitly uses a disclosed justified approximation. An output shape or positive correlation is not independent validation. Existing work directories, cached response files, and provider-derived priors may make comparisons dependent.
