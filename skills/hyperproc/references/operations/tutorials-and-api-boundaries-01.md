## Reference hierarchy

1. Installed exact version source/signature establishes what will execute.
2. Reviewed PyPI 0.1.2 wheel establishes this skill's baseline.
3. Maintained published workflows explain scientific and operational context.
4. Saved notebook outputs show historical examples under specific conditions.

When these differ, state the difference and verify the actual callable and data. A docstring's scientific generalization is not automatically stronger than the maintained workflow caveat. Do not invent a parameter to match a tutorial helper's convenience interface.
