    API reference¶

    The reference covers every local Python module, including public interfaces, lower-level functions, classes, and implementation helpers. Prefer documented package exports for application code. Source-derived does not mean scientifically validated.

    Current snapshot: hyperproc 0.1.1, 53 modules, 459 top-level functions/classes, and 68 public class methods/properties. Every build refreshes signatures, defaults, docstrings, source, and exported-name mappings.

    Where to begin¶

    Task Main namespace
    Open, inspect, export, mask, or analyze hyperproc
    Find granules, check credentials, download, or draw a search map hyperproc.archive
    Airborne topographic/FlexBRDF or satellite NBAR hyperproc.correct
    Atmospheric retrieval orchestration hyperproc.atmos
    Spectral transforms and resampling hyperproc.spectral
